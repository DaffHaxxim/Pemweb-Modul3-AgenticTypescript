Latihan 1

average

tipe dasar · null

Tulis fungsi average(nums: number[]) yang menangani array kosong dengan benar. Pikirkan tipe return yang tepat.

src/01-basic-types.ts

        
Array kosong tidak punya rata-rata. Mengembalikan 0 berarti berbohong, dan NaN tetap bertipe number. Dengan number | null, pemanggil wajib menangani kasus kosong.

      

    

    
Lihat apa yang ditolak compiler
      

        
tambahan di src/index.ts
const m: number = average([1, 2, 3]);

        
src/index.ts(10,7): error TS2322: Type 'number | null' is not assignable to type 'number'.
  Type 'null' is not assignable to type 'number'.

      

    

  


  
  

    
Latihan 2
formatId
union · narrowing

    
Buat formatId(id: string | number): string yang mengembalikan huruf besar untuk string dan angka 6 digit (000482) untuk number.

    

      
src/02-union-narrowing.ts

      

        

          

            
            
          

          
          
        

        

        
Setelah typeof id === "string", TypeScript mempersempit tipe: di dalam if id adalah string, setelahnya pasti number. Coba juga -5 atau 1234567: soal tidak mengatur kasus itu.

      

    

    
Lihat apa yang ditolak compiler
      

        
notes/compile-errors/ex1-ex2-ex5-calls.ts
formatId(true); // only string | number

        
notes/compile-errors/ex1-ex2-ex5-calls.ts(7,10): error TS2345: Argument of type 'boolean' is not assignable to parameter of type 'string | number'.

      

    

  


  
  

    
Latihan 3
PaymentMethod dan describe
discriminated union · never

    
Modelkan PaymentMethod dengan tiga kemungkinan ("card", "transfer", "cash") dengan properti berbeda, lalu buat describe(p) dengan pengecekan kelengkapan memakai never.

    

      
src/03-discriminated-union.ts

      

        

          
          
          
        

        

        

        
Properti kind adalah penanda jenis. Setelah dicek di switch, hanya properti milik jenis itu yang boleh dipakai. Di default, p bertipe never.

      

    

    
Lihat apa yang ditolak compiler: jenis ke-4 yang lupa ditangani
      

        
perubahan di src/03-discriminated-union.ts
  | { kind: "cash"; amount: number }
  | { kind: "crypto"; coin: string };

        
src/03-discriminated-union.ts(21,13): error TS2322: Type '{ kind: "crypto"; coin: string; }' is not assignable to type 'never'.

        
Pesan error langsung menyebut jenis yang belum ditangani. Inilah gunanya pengecekan never.

Latihan 5

generics

    
Buat fungsi groupBy<T, K extends string | number>(items: T[], key: (item: T) => K): Record<K, T[]>.

Latihan 6
fetchJson
async · error handling

    
Tulis fetchJson<T>(url: string): Promise<T> yang melempar Error jika res.ok bernilai false. Diskusikan: apa yang tidak dijamin oleh T?

    

      
src/06-async.ts

      

        
interface User { id: number; name: string }

        

          
          
          
        

        

        
Jawaban diskusi: T tidak menjamin apa pun tentang isi data. as T hanya membuat compiler percaya; tipe dihapus saat kompilasi. Tombol kedua membuktikannya: user.name bertipe string menurut compiler, tetapi isinya undefined.

        
Halaman ini tidak boleh mengakses jaringan, jadi tiga respons di atas dibuat dengan objek Response milik browser. Di proyek asli, npm start memakai URL data: dan satu permintaan sungguhan yang menghasilkan 404.
